## Junior Programmers Group
# Welcome to JPG Game Development Initiative

In this initiative, you will learn the basics of 2D Game Development. For you to experience, we will make games every week with increasing difficulty. 
Each project will cover key topics in game development that you will use in your journey as a tool for solving problems and thinking like a game developer.

This initiative aims to ignite and cultivate students’ passion for game development—especially those in <br><br><b>Computer Science (CS)</b>, <br><b>Information Technology (IT)</b>, and <br><b>Multimedia Arts (MMA)</b> <br><br>
Over the course of two months, participants will learn the foundations of game creation using <b>JavaScript (web-based)</b>, including:
<b>Object-Oriented Programming
Game Programming Fundamentals
Simple Physics & Simulation
Graphics Rendering
Artificial Intelligence for Games
Sprite Animation
Game Design Principles.</b>
Whether you’re a beginner or someone with prior experience, this initiative welcomes all students who want to learn how games work and how to build them from scratch.


# Prerequisites
You are encouraged to join if you possess at least one of the following:
* Basic programming knowledge
* Basic math and physics understanding
* Strong eagerness to learn
* Interest in games or game creation

If you have passion, curiosity, or creativity—you belong here.

# Program Outline

Orientation (date-unknown)

Week 1 - Snake (Basic Input, Drawing Shapes, Fundamentals) - Individual

Week 2 - Pong ( Vector Math, Collision Detection) - Individual

Week 3 - Flappy Bird ( Physics, Image Rendering, Sound, Sprite Animation, Delta Time ) - Individual

Week 4 - Pac Man ( Artificial-Intelligence, Event Triggers ) - Individual

Week 5-6 - Platformer Game like Super Mario (World Scrolling, Advance Collision Detection, Event Triggers, Advance Input Control, Multiple NPC enemies, etc) - By Group

Week 7-9 - Top-Down RPG Rouge-Like (Story-Telling, NPC Dialogue, Map Navigation, Advance Sprite Animation, Particle Effects, in-game HUD, simple inventory management) - By Group
